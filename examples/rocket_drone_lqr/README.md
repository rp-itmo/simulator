Протокол обмена: \*\*ZeroMQ\*\*

# Цель проекта



Разработать систему управления двухмерной ракетой, способной отслеживать заданную траекторию в плоскости X-Z.



Управление осуществляется через реальные силы двигателей:



* F1 — основной двигатель

* F2 — боковой двигатель

* F3 — боковой двигатель



Ракета должна компенсировать действие гравитации и следовать заданной траектории.

# Математическая модель



Состояние ракеты:
```text

x      положение по оси X

z      положение по оси Z



theta  угол корпуса



vx     скорость по X

vz     скорость по Z



omega  угловая скорость

```

Управление:

```text

F1  основная тяга



F2  боковая тяга



F3  боковая тяга

```



В динамическую модель передаются реальные силы двигателей.

# Локальный запуск

Запуск симуляции без разделения процессов:

```bash

python -m examples.rocket\_drone\_lqr.demo\_closed\_loop

```
# Запуск через ZeroMQ
Окно №1:
```bash

python -m examples.rocket\_drone\_lqr.run\_controller

```

Окно №2:


Контроллер и симулятор работают как независимые процессы и обмениваются сообщениями через ZeroMQ.

# Алгоритм управления

В проекте используется Linear Quadratic Regulator (LQR).

PID и PD-регуляторы намеренно не используются, поскольку условия задания требуют применения более продвинутого метода управления.

LQR вычисляет оптимальные управляющие воздействия на основе текущего состояния ракеты и требуемого состояния траектории.

# Протокол обмена

```text

ControlRequest

&#x20;   state

&#x20;   F2

&#x20;   F3

```
